 If your teacher asks only five questions, prepare these first:
1. Constructor: A special member used to initialize an object.
2. Copy constructor: Creates a new object by copying values from an existing object.
3. Constructor overloading: Defining multiple constructors with different parameter lists.
4. new keyword: Creates an object and returns its reference.
5. Default constructor: A no-argument constructor; Java supplies one automatically only when no constructor has been declared.
